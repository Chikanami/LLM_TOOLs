
# Water Sort Puzzle — 离散系统状态空间图生成器

一个通用的**离散动力系统相图生成器**，以水排序谜题为起点，可扩展至并发协议验证、生化反应网络、棋类残局分析、社会传播模型等任意有限状态系统。


试管中装入 N 单位液体，M 种不相溶颜色 → 倾倒操作 → 状态转移图 → SCC 压缩 → 交互式可视化

## 理论基础

### 问题形式化

水排序谜题可建模为**三元组 ⟨S, F, G⟩**：

| 符号 | 含义 | 本案定义 |
|------|------|---------|
| `S` | 状态空间 | 所有可达试管排列构成的集合 |
| `F` | 转移规则 | 合法倾倒操作 → 后继状态映射 |
| `G` | 目标集合 | 每管全空或单色满（容量 N） |

### 状态图 `G = (V, E)`

- **顶点**：可达状态，经试管排序消除置换对称后作为节点
- **边**：一次合法倾倒操作，有向（倾倒通常不可逆）
- **性质**：稀疏有向图，存在环（同色液体可在两管间来回倾倒），存在大量死胡同

### 可解必要条件

1. **颜色整除约束**：每种颜色总量 `V_c ≡ 0 (mod N)`，否则绝对无解
2. **空管缓冲约束**：至少需要 1 个空管作为工作区
3. **容量上界**：总液体量 `≤ (h−1)·N`

### SCC 凝聚

使用 **Tarjan 算法**识别强连通分量（SCC），将每个 SCC 压缩为单一超节点，得到**有向无环图 (DAG)**：

- **单个状态** 退化为平凡 SCC
- **环路**（如 A→B→C→A）压缩为一个 SCC 节点
- **死循环**（dead_cycle）：SCC 内部环路但 DAG 出度为零，无法抵达解

## 功能特性

### 节点分类与染色

| 类型 | 颜色 | 形状 | 含义 |
|------|------|------|------|
| **初始节点** | 🔵 蓝 `#448AFF` | 方框 | 谜题初始状态 |
| **中间节点** | ⬜ 白 `#F5F5F5` | 圆点 | 普通过渡状态 |
| **环节点** | 🟠 橙 `#FFB74D` | 圆点 | SCC 环路（有出路） |
| **死循环节点** | 🟠🔴 橙底红心 | 图片 | SCC 环路（无出路） |
| **死胡同节点** | 🔴 红 `#EF5350` | 圆点 | 出度为 0 的非解节点 |
| **解节点** | 🟢 绿 `#66BB6A` | 方框 | 目标状态 |

### 边染色方案

**有解时**（三角域插值）：

```
          #00FF00 (绿)
          /        \
         /          \
        /  中间过渡   \
       /              \
#00FFFF (青) ——————— #FF0000 (红)
```

- **直连初始** → `#00FF00`（绿）
- **直连解** → `#00FFFF`（青）
- **近初始** → 权重偏绿
- **近解** → 权重偏青
- **远离两者** → `#FF0000`（红）
- **不可达解** → `#CC3333`（暗红，死支）
- **不可达** → `#666666`（灰）

权重函数使用幂指数调整：

```
w_g = (1 − nᵢ)^1.5     绿色权重（近初始）
w_c = (1 − nₛ)^1.5     青色权重（近解）
w_r = (nᵢ · nₛ)^0.7    红色权重（远两者）
```

**无解时**：绿 → 红线性渐变。

## 输入格式

JSON 文件结构：

```json
{
    "Vol": 5,
    "TtList": {
        "tt1": [0, 0, 0, 1, 2],
        "tt2": [1, 2, 3, 1, 1],
        "tt3": [2, 3, 4, 2, 2],
        "tt4": [3, 4, 5, 5, 5],
        "tt5": [1, 0, 4, 5],
        "tt6": [0, 3, 3, 5],
        "tt7": [4, 4, 5, 5],
        "tt8": []
    }
}
```

| 字段 | 类型 | 说明 |
|------|------|------|
| `Vol` | `int` | 试管容量（每个试管最多装 N 单位液体） |
| `TtList` | `object` | 试管映射，key 为试管名，value 为整数列表（**底→顶**） |
| `TtList[key]` | `list[int]` | 从管底到管顶的颜色序列，数字代表颜色，空列表代表空管 |

### 约束

- 颜色用非负整数表示，相同数字 = 相同颜色
- 列表顺序：**index 0 = 管底，index −1 = 管顶**
- 试管数量 `h` 无上限（受搜索上限 50000 状态约束）
- 颜色种类无显式上限

## 输出说明

生成自包含的 HTML 文件，无需任何外部依赖（vis.js 从 CDN 加载）。

### 布局模式

| 模式 | 适用场景 | 特点 |
|------|---------|------|
| **力导向布局**（默认） | 探索性浏览、中小图 | 动态物理模拟，节点排斥、边吸引 |
| **层级布局** | 大图、追踪解路径 | 按 `d_init` 分层，LR 方向，完全静态 |

### 典型工作流

1. **力导向模式**入场，观察全局拓扑
2. 点击 **📍 初始节点** 定位起点
3. 若存在解，点击 **🎯 解节点** 定位终点 → 视觉追踪青→绿路径
4. 切换到 **🏗️ 层级布局** 获取干净的分层视角
5. 发现红色/暗红区域 = 死胡同/死支，应避免
6. **⏸️ 暂停物理** 冻结布局，仔细研究

## 用法示例

### 示例 1：简单可解谜题

```json
{
    "Vol": 2,
    "TtList": {
        "tt1": [1, 2],
        "tt2": [1, 2],
        "tt3": []
    }
}
```

```
试管容积=2, 试管数=3 | 可达状态: 8–12 | SCC: 1–2 | 有解
```

### 示例 2：无解谜题（违反整除约束）

```json
{
    "Vol": 3,
    "TtList": {
        "tt1": [1, 1, 2],
        "tt2": [2, 2, 1],
        "tt3": []
    }
}
```

颜色 1 总量 = 3（整除 ✓），颜色 2 总量 = 3（整除 ✓），但起始布局导致某些状态不可达解。程序会自动检测并标记为"无解"，边颜色仅使用绿→红渐变。

### 示例 3：存在环路

任何两个试管装相同颜色顶层液体、且有足够空间的配置，都可能产生来回倾倒的环路。程序自动通过 Tarjan 合并环路，并以橙色标记。

## 算法详解

### 1. 状态规范化 (`canonicalize`)

```python
def canonicalize(state):
    return tuple(sorted(state))
```

试管排列顺序无关——`(管A, 管B) ≡ (管B, 管A)`。通过对试管元组排序，所有对称排列坍缩为同一节点。

**效果**：状态空间压缩至原来的 `1/h!`。

### 2. BFS 枚举 (`explore`)

```
procedure explore(Vol, init):
    Q ← deque([init])
    while Q not empty:
        cur ← Q.popleft()
        for each next in get_next_states(cur):
            if next not in visited:
                visited[next] ← idx
                states.append(next)
                Q.append(idx)
            edges.append((cur_idx, next_idx))
```

- 时间复杂度：`O(V·h² + E)`，h 为试管数
- 空间复杂度：`O(V)`（状态哈希表）
- 硬上限 50000 状态，可修改 `max_states` 参数

### 3. Tarjan SCC 分解

标准 Tarjan 算法，`O(V+E)` 时间，单次 DFS 完成。

```
indices[v] ← 发现时间戳
lowlink[v] ← 通过后代边能到达的最早节点
当 lowlink[v] == indices[v] 时，栈中 v 及以上的节点构成一个 SCC
```

### 4. 距离计算 (双端 BFS)

```
正向 BFS（从初始出发）→ d_init[scc]
反向 BFS（从所有解出发）→ d_sol[scc]
```

- 不可达初始 → d_init 缺失
- 不可达解 → d_sol 缺失 → 标记为死支（暗红边）

### 5. 边颜色插值

见[边染色方案](#边染色方案)。核心改进：对权重使用**非线性幂函数**，使中等距离区域产生肉眼可辨的红色分量。

## 性能优化

### 已实现

| 优化 | 效果 |
|------|------|
| **试管排序对称压缩** | 状态数 ÷ h! |
| **SCC 凝聚** | 图规模缩减 5–50%（取决于环路密度） |
| **去重边集** | DAG 边数 ≤ SCC 数² |
| **层级布局** | 完全静态，零计算开销 |
| **物理暂停** | 冻结力导向模拟，大图流畅 |

### 优化思路（未实现，供扩展参考）

| 方案 | 预估效果 | 实现难度 |
|------|---------|---------|
| **链式节点折叠** | 合并入度=出度=1 的中间 SCC，减 30–50% 节点 | 中 |
| **WebGL 渲染器** | vis.js 支持 `renderer: 'webgl'`，万级节点流畅 | 低 |
| **dagre 预计算布局** | 用 Sugiyama 算法预计算坐标，写入静态 JSON | 中 |
| **边简化** | 合并平行边为单边，线宽表示多重性 | 中 |
| **视口裁剪** | 仅渲染可视区域（vis.js 已部分实现） | — |
| **分层分页** | 按距离分层，一次只显示 2–3 层 | 高 |

## 扩展应用

本程序的核心抽象是**三元组 ⟨S, F, G⟩ 状态空间搜索器**，替换三个函数即可适配任意离散系统：

```python
# 需替换的三个函数
get_next_states(Vol, state) → List[state]   # 转移规则 F
is_solution(Vol, state)      → bool          # 目标谓词 G
canonicalize(state)          → state         # 对称性压缩
```

### 可直接适配的问题

| 领域 | 问题 | 状态编码 | 转移规则 |
|------|------|---------|---------|
| **AI 经典** | 传教士与野人 | `(M左, C左, 船位置)` | 划船操作 |
| **AI 经典** | 汉诺塔 | `(盘1位置, 盘2位置, …)` | 移动某盘 |
| **AI 经典** | 过河问题 | `(人,狼,羊,草)` 0/1 | 过河操作 |
| **并发** | 死锁检测 | `(进程状态, 锁状态)` | 进程执行一步 |
| **化学** | 反应网络 | `(A浓度, B浓度, …)` | 反应发生 |
| **生物** | 基因调控布尔网络 | `(基因1, 基因2, …)` 0/1 | 基因翻转 |
| **棋类** | 残局分析 | 简化棋盘 | 合法走法 |
| **社会** | 观点传播 | `(采纳比例1, 比例2, …)` | 邻居影响 |
| **工作流** | 流程验证 | `(步骤, 审批人, 文档)` | 审批操作 |

### 概念对应

| 节点类型 | 并发程序语义 | 化学网络语义 | 棋类语义 |
|---------|------------|------------|---------|
| 解节点 | 正常终止 | 目标产物 | 必胜态 |
| 死胡同 | 死锁 | 反应无法继续 | 必败态 |
| 环路 SCC | 活锁 | 可逆反应平衡 | 循环局面 |
| 死循环 | 活锁陷阱 | 无用循环 | 三次重复 |
| 不可达解 | 死代码路径 | 不可达产物 | 理论必胜不可达 |

本质上，这是一个**离散动力系统的相图（phase portrait）生成器**——与微分方程的相图分析同构，只是将连续轨线替换为离散状态转移。
