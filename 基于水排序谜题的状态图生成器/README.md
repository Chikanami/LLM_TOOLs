# Water Sort Puzzle — 状态空间图生成器

**离散动力系统相图工作台 · 不止于水排序**

---

## 概述

给定一个 **Water Sort Puzzle（水排序谜题）** 的初始条件，本程序：

1. **枚举完整状态空间** —— BFS 遍历所有合法倾倒操作可达的状态
2. **压缩对称性** —— 试管排列顺序无关的物理状态坍缩为单节点
3. **压缩环路** —— Tarjan 算法识别强连通分量（SCC），环路折叠为超节点
4. **染色分类** —— 初始节点、中间节点、环节点、死循环节点、死胡同节点、解节点
5. **边距离染色** —— 根据节点距初始状态和解状态的距离，以绿–青–红连续过渡色渲染有向边
6. **输出交互式 HTML** —— 基于 vis.js 的力导向图，支持层级布局切换、节点定位、物理模拟控制

> 核心抽象：一个 **⟨初始状态, 操作集, 目标集⟩** 三元组的通用状态空间探索器。水排序只是它恰好穿上的第一件外衣。

## 数学模型

### 状态表示

每个试管是一个从底到顶的颜色序列（栈）。全局状态为 $h$ 个试管的有序元组：

```
状态 ∈ { (tube₁, tube₂, ..., tube_h) | tubeᵢ = (c₁, c₂, ..., cₖ), k ≤ N }
```

通过 `canonicalize()` 对试管元组排序，消除试管排列的 $h!$ 重对称性。

### 合法操作（倾倒）

从试管 $i$ 倒入试管 $j$（$i \neq j$）需满足：

1. $i$ 非空
2. $j$ 为空 **或** $\text{top}(i).\text{color} = \text{top}(j).\text{color}$
3. $j$ 未满（$\text{len}(j) < N$）

倾倒量 = $\min(\text{顶部连续同色层体积},\ N - \text{len}(j))$

### 目标状态

对每个试管，满足以下之一：

- **全空**：$\text{len} = 0$
- **单色满**：$\text{len} = N$ 且所有元素颜色相同

### 可解必要条件

| 条件 | 说明 |
|------|------|
| 颜色整除 | 每种颜色的总量必须是 $N$ 的整数倍 |
| 空管缓冲 | 至少需要 1 个空试管作为工作区 |
| 容量约束 | 总液体量 $\le (h-1) \cdot N$ |

### 状态图 $G = (V, E)$

| 性质 | 值 |
|------|-----|
| 有向性 | 倾倒通常不可逆 |
| 存在环 | 同色液体可在两管间来回倾倒 |
| 非强连通 | 大量状态互相不可达 |
| 稀疏 | 平均出度 $\ll h(h-1)$ |
| 判定复杂度 | NP-hard（归约自广义汉诺塔） |

## 特性

### 节点分类与视觉

| 类型 | 颜色 | 形状 | 含义 |
|------|------|------|------|
| **初始节点** | 蓝 `#448AFF` | 方框 | 谜题初始状态所在的 SCC |
| **中间节点** | 白 `#F5F5F5` | 圆点 | 一般可达状态 SCC |
| **环节点** | 橙 `#FFB74D` | 圆点 | SCC 含多个状态（存在循环） |
| **死循环节点** | 橙底红心 | 双圆 SVG | SCC 含循环且无出路 |
| **死胡同节点** | 红 `#EF5350` | 圆点 | DAG 出度为 0 的非解节点 |
| **解节点** | 绿 `#66BB6A` | 方框 | 包含目标状态的 SCC |

### 边颜色语义

以目标节点距初始状态（$d_{\text{init}}$）和距解（$d_{\text{sol}}$）的距离插值：

| 颜色 | hex | 条件 |
|------|-----|------|
| 🟢 绿 | `#00FF00` | 直接出自初始节点 |
| 🔵 青 | `#00FFFF` | 直接连解节点 |
| 🔴 红 | `#FF0000` | 远离初始和解两者 |
| 🟤 暗红 | `#CC3333` | 可达初始但不可达任何解 |
| ⚫ 灰 | `#666666` | 不可达 |

插值公式（有权重函数）：

```
w_green = (1 − n_init)^1.5     ← 靠近初始时主导
w_cyan  = (1 − n_sol)^1.5     ← 靠近解时主导
w_red   = (n_init · n_sol)^0.7 ← 两者都远时主导（幂函数放大）
```

无解时退化为绿→红线性渐变。

### 交互功能

| 操作 | 方式 |
|------|------|
| 定位初始节点 | 按钮 **📍 初始节点** 或按 `I` 键 |
| 定位解节点 | 按钮 **🎯 解节点** 或按 `S` 键 |
| 切换层级布局 | 按钮 **🏗️ 层级布局** 或按 `L` 键 |
| 暂停/恢复物理 | 按钮 **⏸️ 暂停物理** 或按 `P` 键 |
| 拖拽/缩放 | 鼠标操作（vis.js 默认） |

## 安装与使用

### 依赖

- Python 3.7+
- 无第三方 Python 包（仅标准库）
- 浏览器（用于查看 HTML 输出，vis.js 通过 CDN 加载）

### 运行

```bash
# 从 JSON 文件读取
python water_sort_graph.py input.json

# 指定输出路径
python water_sort_graph.py input.json -o my_graph.html

# 从标准输入读取
python water_sort_graph.py < input.json
```

输出文件：
- 指定 `-o` 时使用该路径
- 从文件读取且未指定 `-o` 时，输出为 `{原文件名}_graph.html`
- 从 stdin 读取时，默认输出 `water_sort_graph.html`

### 输入格式

```json
{
    "Vol": 5,
    "TtList": {
        "tt1": [0, 0, 0, 1, 2],
        "tt2": [1, 2, 3, 1, 1],
        "tt3": [2, 3, 4, 2, 2],
        "tt4": [3, 4, 5, 5, 5],
        "tt5": [1, 0, 4, 5],
        "tt6": [0, 3, 3, 5],
        "tt7": [4, 4, 5, 5],
        "tt8": []
    }
}
```

| 字段 | 类型 | 说明 |
|------|------|------|
| `Vol` | int | 试管容量 $N$ |
| `TtList` | object | 试管映射，key 任意（如 `tt1`），value 为颜色列表（栈底→栈顶） |
| `TtList.*` | `int[]` | 空数组 `[]` 表示空试管；颜色用整数 0,1,2,… 表示 |

## 架构

```
canonicalize()        ← 对称性压缩（试管排序）
get_top_layer()       ← 栈顶颜色层获取
is_solution()         ← 目标状态判定
get_next_states()     ← 操作集 F（合法倾倒枚举）
explore()             ← BFS 全状态空间枚举
tarjan()              ← Tarjan SCC 分解
condense()            ← DAG 凝聚
classify_nodes()      ← 节点分类（五类）
compute_distances()   ← BFS 计算 d_init / d_sol
edge_color()          ← 权重插值边染色
build_html()          ← 自包含 HTML 组装
```

核心三个"可热插拔"函数：

```python
get_next_states(Vol, state) → List[state]    # 换这个 → 换系统
is_solution(Vol, state)     → bool           # 换这个 → 换目标
canonicalize(state)         → canonical_state # 换这个 → 换对称性模型
```

## 更多应用场景

这个程序本质是一个**离散动力系统相图生成器**。替换三个核心函数即可分析完全不同的系统：

| 领域 | 状态编码 | 操作 | 目标 |
|------|---------|------|------|
| **经典 AI 谜题** | 汉诺塔/传教士与野人/过河问题 | 游戏规则 | 完成状态 |

| **棋类残局** | 棋盘局面 | 合法走法 | 将死/和棋 |

### 对应关系

| 你的模块 | 并发系统语义 | 化学网络语义 |
|---------|------------|------------|
| SCC 环路 | 活锁循环 | 可逆反应平衡 |

## 大规模图性能优化

| 方案 | 效果 | 代价 |
|------|------|------|
| **层级布局** | 已内置，一键切换，DAG 直观 | 禁用物理 |
| **物理暂停** | 已内置，大图防卡顿 | 节点不可拖拽 |
| 链式节点折叠 | 合并出度=入度=1 的中间 SCC，减 30-50% 节点 | 损失细节 |
| WebGL 渲染 | vis.js 支持，万级节点流畅 | 样式受限 |
| 预计算静态坐标 | dagre 算法预计算，完全禁用物理 | 不可拖拽 |
| 边简化 | 合并平行边，线宽表示多重边 | 实现复杂 |
